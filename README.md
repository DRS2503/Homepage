# Homepage
Project to create a responsive template homepage.

## Why I did this project
This project was to focus on designing a website using Accessibility and responsive techniques I learned in The Odin Project. These techniques include semantic HTML, responsive images, and media queries.

## Requirements
To run this yourself all you have to do is pull the repo, and copy the file path to index.html in your browser. This website is not hosted because it is just practice.
